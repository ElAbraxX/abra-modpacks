Elige cómo jugar

ZIP DE CURSEFORGE

Con CurseForge App

  1. Descarga el ZIP de tu pack.
  2. Abre CurseForge y selecciona Minecraft.
  3. Importa un perfil desde el archivo ZIP.
  4. Espera a que se preparen Minecraft y los mods.
Descargar CurseForge ↗
.MRPACK · WINDOWS

Con el instalador Abra

  1. Abre una vez el launcher oficial y después ciérralo.
  2. Descarga el .mrpack y el instalador.
  3. Haz doble clic en el .exe, elige el pack y pulsa Instalar.
  4. Abre el launcher oficial y selecciona el perfil del pack.
Descargar instalador Windows ↓

Incluye Python y prepara Java. Los mods van a .minecraft/abra-packs, separados de tus mundos. Necesitas internet y una cuenta con Minecraft Java.

También puedes importar los .mrpack en Modrinth App o Prism Launcher. El instalador Abra no admite ZIP de CurseForge.

PUBLICAR UN PACK

Sube el archivo a GitHub

Para este alojamiento gratuito, los archivos se guardan en las publicaciones de tu repositorio.

  1. Pulsa «Publicar modpack».
  2. Crea una etiqueta nueva y escribe el nombre del pack como título.
  3. Indica Minecraft y el cargador en la descripción.
  4. Adjunta tu .mrpack o ZIP exportado de CurseForge, de hasta 1 GB, y publica.
Publicar modpack en GitHub ↗

El título de la publicación será el nombre mostrado en la página. Pon también ese nombre al archivo antes de subirlo: el instalador usa el nombre del .mrpack como perfil.
