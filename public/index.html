Cómo instalar tu formato

CurseForge · ZIP

Para archivos ZIP exportados desde CurseForge.

CurseForge App

  1. Descarga el ZIP del pack.
  2. Abre CurseForge y selecciona Minecraft.
  3. Importa un perfil desde archivo y elige ese ZIP.
  4. Espera a que termine la instalación.
Descargar CurseForge ↗

Prism Launcher

  1. Descarga el ZIP del pack.
  2. En Prism pulsa Añadir instancia → Importar.
  3. Selecciona el ZIP y sigue las indicaciones.
Descargar Prism Launcher ↗

Modrinth · MRPACK

Para archivos con extensión .mrpack.

Modrinth App

  1. Descarga el archivo .mrpack.
  2. Abre Modrinth App e importa el pack desde archivo.
  3. Selecciona el .mrpack y espera a que termine.
Descargar Modrinth App ↗

Prism Launcher

  1. Descarga el archivo .mrpack.
  2. En Prism pulsa Añadir instancia → Importar.
  3. Selecciona el .mrpack y sigue las indicaciones.
Descargar Prism Launcher ↗

Instalador Abra · Windows

  1. Abre una vez el launcher oficial y después ciérralo.
  2. Descarga el .mrpack y el instalador.
  3. Abre el .exe, elige el .mrpack y pulsa Instalar.
  4. Al terminar, abre el launcher oficial y selecciona el perfil del pack.
Descargar instalador Windows ↓

PUBLICAR UN PACK

Sube el archivo a GitHub

Para este alojamiento gratuito, los archivos se guardan en las publicaciones de tu repositorio.

  1. Pulsa «Publicar modpack».
  2. Crea una etiqueta nueva y escribe el nombre del pack como título.
  3. Indica Minecraft y el cargador en la descripción.
  4. Arrastra una imagen al cuadro de descripción de GitHub: la primera imagen será la portada de la tarjeta.
  5. Adjunta tu .mrpack o ZIP exportado de CurseForge, de hasta 1 GB, y publica.
Publicar modpack en GitHub ↗

El título de la publicación será el nombre mostrado en la página. Pon también ese nombre al archivo antes de subirlo: el instalador usa el nombre del .mrpack como perfil.
